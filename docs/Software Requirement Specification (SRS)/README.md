# Software Requirement Specification (SRS)

Tài liệu đặc tả yêu cầu phần mềm cho dự án **Zoom Education Platform**.

### Danh sách tài liệu con:
* [01. Functional Requirements](01_Functional_Requirements.md) — Đặc tả yêu cầu chức năng hệ thống.
* [02. Non-Functional Requirements](02_Non_Functional_Requirements.md) — Đặc tả yêu cầu phi chức năng (hiệu năng, bảo mật, độ tin cậy).
* [03. System Constraints](03_System_Constraints.md) — Các ràng buộc kỹ thuật và vận hành.
