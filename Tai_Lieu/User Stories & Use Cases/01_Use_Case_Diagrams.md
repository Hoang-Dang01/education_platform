# 01. Use Case Diagrams (Sơ đồ ca sử dụng)

Tài liệu này định nghĩa ranh giới hệ thống (System Boundary), danh sách tác nhân (Actors) và các sơ đồ Use Case tổng quát và chi tiết cho từng tác nhân trong hệ thống **Zoom Education Platform**.

---

## 1.1. Danh sách tác nhân (Actors) và Trách nhiệm

Dưới đây là bảng định nghĩa các tác nhân tương tác trực tiếp với hệ thống:

| Tác nhân (Actor) | Vai trò trong hệ thống | Trách nhiệm chính |
| :--- | :--- | :--- |
| **Student (Học viên)** | Người tham gia học tập | - Tham gia lớp học trực tuyến.<br>- Thực hiện tương tác, điểm danh.<br>- Xem tài liệu và bài giảng ghi hình. |
| **Teacher (Giáo viên)** | Người chủ trì lớp học (Host) | - Quản lý phòng học trực tuyến (Mở/khóa phòng, ghi hình).<br>- Tổ chức điểm danh, breakout rooms.<br>- Upload tài liệu giảng dạy. |
| **Admin (Quản trị viên / Vận hành)** | Người quản trị hệ thống | - Quản lý tài khoản, phân quyền.<br>- Cấu hình Feature Flags, giám sát hệ thống.<br>- Xử lý sự cố qua nhật ký telemetry. |
