# 03. Data Migration Strategy (Chiến lược di chuyển dữ liệu)

## 3.1. Các giai đoạn di chuyển dữ liệu (Migration Phases)
1. Trích xuất dữ liệu cũ (Extract)
2. Chuyển đổi và làm sạch (Transform & Cleanse)
3. Nạp vào hệ thống mới (Load)
4. Đối soát dữ liệu (Reconciliation)
